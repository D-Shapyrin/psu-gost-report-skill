# Результаты работы

## Были изучены классы и политики планирования процессов ОС Linux

Ядро разделяет процессы на классы справедливого планирования, реального времени и класса простоя, каждому классу соответствует набор политик. Для обычных задач применяется политика SCHED_OTHER, для пакетных — SCHED_BATCH, для фоновых — SCHED_IDLE.

## Были исследованы приоритеты процессов и продемонстрировано их изменение

Результаты замеров приведены в таблице 1.

: Таблица 1 – Результаты замеров

| Приоритет | Время, с | Загрузка CPU, % |
|:---------:|:--------:|:---------------:|
| 0         | 12,4     | 25              |
| -10       | 8,1      | 48              |

Доля процессорного времени при конкуренции пропорциональна весу процесса:

$$ w_i = 1024 \cdot 1{,}25^{-n_i} $$

где w_i — вес процесса, n_i — значение nice.

Скрипт запуска приведён в листинге 1.

```bash
#!/bin/bash
nice -n -10 ./worker &
wait
echo "done"
```
