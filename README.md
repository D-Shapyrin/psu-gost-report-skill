# Оригинальный репозиторий https://github.com/Bbar0n234/gost-report-skill

Скилл для AI-агента, который оформляет студенческие работы по ГОСТ 7.32: лабораторные, курсовые, ВКР (текстовая часть), отчёты по практике, рефераты, контрольные.

Принцип: **нейросеть пишет только текст, форматирование детерминировано.** Агент разбирается в вашей методичке, согласовывает с вами структуру и пишет содержание — а стили, титульный лист и вёрстку накладывает скрипт. Поэтому «съехавшее оформление» исключено по построению: Times New Roman 14 pt, полуторный интервал, красная строка 1,25 см, поля по ГОСТ — всегда на месте, и это дополнительно проверяется автоматическими проверками после каждой сборки.

## Как это выглядит

```
Вы:    Оформи отчёт по лабораторной №3 по операционным системам, вот методичка
Агент: [читает методичку] → предлагает структуру → согласовывает с вами
       → пишет текст → собирает report.docx с титульником и оформлением
```

Полный пример готовой работы — от исходного текста до собранных .docx и .pdf — в [examples/full_lab](gost-lab-report/examples/full_lab).

## Что умеет

- **Все текстовые типы работ** — от лабораторной на 15 страниц до текста ВКР: структура подбирается под тип работы и вашу методичку.
- **Титульный лист вашего вуза** — заполняется автоматически (ФИО, группа, дисциплина, тема, год). В комплекте профиль ПГУ ИБСТ (по умолчанию: `templates/my/` — титульники лабораторной и курсовой, стили по распоряжению кафедры, выжимка требований в `RULES.md`) и профиль-пример ГУАП/СПбГЭУ (`templates/from_the_repository/`).
- **Профили вузов подключаемые**: у каждого вуза своя папка `templates/<profile>/` — свой `reference.docx` (поля, шрифт, интервалы, нумерация списков, колонтитулы) и реестр титульников. Выбор — YAML-поле `profile`.
- **Нет вашего вуза — агент подключит его сам**: дайте ему .docx-бланк титульника (.doc тоже подойдёт — сконвертирует), он превратит бланк в шаблон, прогонит тесты и покажет результат вам на приёмку. Это разовая настройка.
- **Автоматическое ОГЛАВЛЕНИЕ** с настоящими номерами страниц.¹
- **По ГОСТу и по кафедре — всё, что болит на защите**: нумерация разделов «1.1» без точки, подписи «Рисунок 1 –» / «Таблица 1 –», приложения «ПРИЛОЖЕНИЕ А», список источников по ГОСТ 7.0.100 (для ПГУ — по ГОСТ Р 7.0.5-2008), реферат ВКР с автоподсчётом страниц и рисунков. Для ПГУ дополнительно: поля 30/10/20/20 мм, перечисления только дефисом, формулы с номером справа «(1)», децимальный номер на титуле курсовой, номера страниц внизу по центру без номера на титуле.
- **Самопроверка перед сдачей**: агент прогоняет собранный документ через автоматические проверки оформления и чек-лист ГОСТ и сам смотрит рендер глазами.

¹ Word не пересчитывает содержание сам — обычно студенты жмут Ctrl+A → F9 перед печатью. Скилл делает это за вас при сборке, если установлен LibreOffice; без него — то же самое одно нажатие F9 в Word.

## Установка

Скилл следует открытому стандарту [Agent Skills](https://agentskills.io) и работает в любом совместимом агенте:

```bash
git clone https://github.com/Bbar0n234/gost-report-skill.git
```

| Агент | Куда положить папку `gost-lab-report/` |
|---|---|
| Claude Code | `~/.claude/skills/` (Windows: `%USERPROFILE%\.claude\skills\`) |
| Codex CLI | `~/.agents/skills/` |
| opencode | `~/.config/opencode/skills/` |

Из зависимостей обязательны только лёгкие: `pandoc` и `pip install python-docx docxcompose`. LibreOffice — опционален и нужен ровно для одного: автоматически пересчитывать СОДЕРЖАНИЕ¹. Агент сам подскажет, чего не хватает, — и не будет ставить тяжёлые пакеты без вашего согласия.

## Совместимость

| Платформа | Сборка .docx | Авто-СОДЕРЖАНИЕ¹ |
|---|---|---|
| Linux (Ubuntu, Debian, Fedora) | ✅ | ✅ |
| Windows | ✅ | F9 в Word (в WSL — автоматически) |
| macOS | ✅ | F9 в Word |

Проверено автотестами на каждой платформе при каждом изменении (бейдж сверху — их текущий статус). Нестабильное или экзотическое окружение? Сборка спокойно живёт в Docker-контейнере Ubuntu — движку всё равно, где выполняться.

## Границы

Честно о том, чего скилл не делает:

- Титульники подключаются из .docx-бланков; старый .doc сначала конвертируется в .docx (PDF не конвертируется — вёрстка по картинке не воссоздаётся).
- Подписные бланки — задание, календарный план, дневник практики, отзывы — не генерируются: их вы вкладываете сами.
- Рамки по ЕСКД и печати — вне скоупа.
- Типографика задаётся `templates/<profile>/reference.docx` (для профиля `my` — требования ПГУ ИБСТ: поля 30/10/20/20 мм, TNR 14 пт, полуторный интервал, отступ 1,25 см); если вуз требует другого — это правится в reference.docx профиля, нейросеть стили не меняет.
