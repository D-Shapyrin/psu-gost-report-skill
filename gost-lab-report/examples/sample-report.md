# 1 Цель работы

Настроить статическую маршрутизацию в сети, состоящей из трёх маршрутизаторов, и проверить связность всех подсетей.

# 2 Задание к лабораторной работе

## 2.1 Изучить принципы статической и динамической маршрутизации

## 2.2 Развернуть сеть из трёх маршрутизаторов и настроить адресацию подсетей

## 2.3 Настроить статические маршруты и проверить связность между подсетями

# 3 Результаты работы

## 3.1 Были изучены принципы статической и динамической маршрутизации

Маршрутизация является одним из ключевых процессов в компьютерных сетях, обеспечивающим передачу пакетов данных между различными сетевыми сегментами. Маршрутизатор анализирует заголовок пакета и принимает решение о его дальнейшей пересылке на основании таблицы маршрутизации, которая может заполняться двумя способами.

При статической маршрутизации маршруты задаются вручную администратором сети: это обеспечивает полный контроль над путями передачи данных, но не даёт автоматической адаптации при изменении топологии сети.

Динамическая маршрутизация основана на специализированных протоколах (RIP, OSPF, BGP), которые автоматически обновляют таблицы маршрутизации при изменении состояния сети; наиболее распространённым для внутридоменной маршрутизации является протокол OSPF.

# 4 Вывод

В результате выполнения работы была настроена статическая маршрутизация в сети из трёх маршрутизаторов и проверена связность всех подсетей. Проверка показала корректную работу всех маршрутов, что соответствует поставленной цели.

Статическая маршрутизация обеспечивает предсказуемую передачу данных и не создаёт дополнительной нагрузки на сеть служебным трафиком. Однако при увеличении количества сетевых сегментов рекомендуется переход на динамическую маршрутизацию с использованием протокола OSPF.
