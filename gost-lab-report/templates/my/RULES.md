# Требования ПГУ (кафедра ИБСТ) к оформлению курсовых и лабораторных работ

Источники:

- Положение о курсовом проектировании обучающихся ПГУ (введено с 1.04.2016) — `templates/my/Положение о курсовом проектировании обучающихся (164337 v1)(1).pdf`.
- Распоряжение кафедры ИБСТ от 07.02.2018 № ___ «Об утверждении требований к структуре и оформлению курсовых проектов и работ» — `templates/my/Распоряжение по требованиям к оформлению КП и ТЗ на кафедре ИБСТ_2018_02.pdf`.
- Титульный лист курсовой работы БСБД 100503 — `templates/my/Титульный лист КР БСБД 100503.doc`.
- Титульник и структура отчёта по лабораторной работе (шаблон кафедры) — `templates/my/Шапырин лабораторная работа № .docx`.

**Приоритет требований:** методичка/положение вуза > профиль скилла (этот файл) > ГОСТ 7.32. Если в методичке есть своё указание — следуем ему, а не здесь описанному дефолту.

## Титульный лист

Оформляется по вузу пользователя из реестра `templates/<profile>/title_pages/registry.yaml`. Профиль по умолчанию в этой сборке — `my` (ПГУ ИБСТ).

Титул курсовой (БСБД 100503) содержит:

- МИНИСТЕРСТВО НАУКИ И ВЫСШЕГО ОБРАЗОВАНИЯ РФ / ПЕНЗЕНСКИЙ ГОСУДАРСТВЕННЫЙ УНИВЕРСИТЕТ / Кафедра «Информационная безопасность систем и технологий»
- «Курсовая работа», «по дисциплине «…», на тему «…» (вариант указывается в теме, если есть)
- Децимальный номер: `ПГУ.<код специальности>.<номер дисциплины>.<КР|КП>.<номер зачётки>.<номер документа>.<обозначение>`,
  пример: `ПГУ.100503.С1118.КР.<номер зачётки>.01.ПЗ`
- Специальность — 10.05.03 Информационная безопасность автоматизированных систем
- Специализация — 6 Защищенные автоматизированные системы управления
- Выполнил студент, Группа, Руководитель (должность, учёная степень, звание), «Работа защищена с оценкой», Дата защиты, год

Титул лабораторной (по шаблону кафедры):

- «Отчёт о лабораторной работе № …», «на тему «…»», Дисциплина, Группа, Выполнил, Количество баллов, Дата сдачи, Принял, год.

## Общее оформление тела (Распоряжение кафедры ИБСТ)

- Листы А4. Поля: левое — 30 мм, правое — 10 мм, верхнее — 20 мм, нижнее — 20 мм.
- Шрифт Times New Roman, 13 или 14 пт (скилл фиксирует 14 пт), только чёрный цвет.
- Межстрочный интервал — полуторный; абзацный отступ — 1,25 см; выравнивание по ширине.
- Интервал между абзацами не допускается.
- Подчёркивание не допускается; допускается выделение жирным/курсивом только для терминов; не допускается изменение масштаба, смещения, зачёркивания, теней, контуров.
- Каждый структурный элемент содержания начинается с новой страницы.
- Наименование структурных элементов — по центру строки, без точки в конце, без подчёркивания, отделяется от текста двумя межстрочными интервалами. Названия глав и параграфов — с прописной буквы, остальные строчные.
- Структура курсовой работы / пояснительной записки к курсовому проекту: титульный лист → задание → оглавление → введение → основной текст (главы, параграфы) → заключение → список использованных источников → приложения.
- Объём курсовой работы: 20–25 страниц текста без приложений; курсовой проект: 30–40 страниц текста и 2–4 листа чертежей.

## Заголовки и нумерация

- Разделы пронумерованы «1», «1.1», «1.1.1» — без точки после номера. Структурные элементы и приложения — без номеров.
- В оглавлении заголовок параграфа сдвинут на абзацный отступ вправо относительно названия главы (показывает структуру работы).
- ПГУ использует заголовок «ОГЛАВЛЕНИЕ» (а не «СОДЕРЖАНИЕ») — задаётся YAML-полем `toc_title`.

## Иллюстрации и таблицы

- Иллюстрация размещается непосредственно после текста, в котором упоминается впервые; на каждую есть ссылка в работе. Подпись под иллюстрацией: «Рисунок N – Название» (тире, без точки в конце), по центру; пояснительные данные под иллюстрацией; нумерация сквозная.
- Таблица — после текста или на следующей странице; название над таблицей слева без абзацного отступа: «Таблица N – Название» (без точки в конце); ссылка в тексте.

## Формулы

- Выделяются в отдельную строку; выше и ниже — не менее одной строки. Номер — арабскими цифрами в круглых скобках справа от формулы, сквозная нумерация по работе (в приложениях — А.1, А.2…). Сразу после формулы — расшифровка входящих величин.

## Перечисления и примечания

- Перед каждым элементом перечисления — дефис (другие маркеры не допускаются), абзацный отступ. Максимум два уровня вложенности: первый уровень — а) б) в) (или дефис), второй — 1) 2).
- Примечание оформляется как «Примечание – текст».

## Источники

- Оформляются по ГОСТ Р 7.0.5-2008 (кафедральное требование; Положением также упоминается ГОСТ 7.1-2003 — при спорах следует актуальному распоряжению кафедры).
- Ссылки в тексте — `[N]`; каждый источник из списка процитирован хотя бы один раз.
- Заголовок раздела: «СПИСОК ИСПОЛЬЗУЕМЫХ ИСТОЧНИКОВ» (именно «использованных»).

## Приложения

- Каждое приложение начинается с новой страницы. Заголовок «ПРИЛОЖЕНИЕ А» прописными буквами по центру; название приложения — следующей строкой, также по центру.
- Буквы по порядку без Ё, З, Й, О, Ч, Ъ, Ы, Ь. Тип приложения в скобках: обязательное / рекомендуемое / справочное.
- Рисунки/таблицы внутри приложений нумеруются отдельно: «Рисунок А.1», «Таблица А.1». На каждое приложение есть ссылка из текста.

## Нумерация страниц

- Арабскими, сквозная нумерация по всей работе, в центре нижнего поля, без точки и без оформления.
- На титульном листе номер не проставляется, но титул учитывается в общем счёте.

## Лабораторная работа (структура по шаблону кафедры)

Титульный лист — по вузу (для ПГУ ИБСТ — шаблон `pgu_lab`). Содержание обычно не нужно. Структура отчёта — строго по шаблону кафедры, с нумерацией разделов (`number_headings: "true"`):

1. **Цель работы** — обязательно, одно-два предложения, берется дословно из методички.
2. **Задание к лабораторной работе** — если в методичке пронумерованный список заданий, вставлять дословно подразделами 2.1, 2.2… по пунктам задания.
3. **Результаты работы** — обязательно; подразделы 3.1, 3.2… по результатам, каждый закрывает соответствующий пункт задания (нумерация 3.x не обязана совпадать с 2.x). Заголовок подраздела — формулировка сделанного: «Был создан новый проект, при этом тип используемой микросхемы ПЛИС был установлен аналогично лабораторной работе №1…».
4. **Вывод** — обязательно, в единственном числе, начинается словами «В результате выполнения работы был…», перекликается с целью.

Отдельных разделов «Краткие теоретические сведения», «Ход работы», «Тестирование», «Вариант» нет: теория, ход действий и скриншоты идут внутри подразделов результатов, вариант — строкой в цели. Дополнительный раздел — только по прямому требованию методички/преподавателя, тогда последующие номера сдвигаются (вывод может стать разделом 5).

## Важное про подписные бланки

Задание, календарный план, отзывы, рецензии — подписные, скилл не генерирует. Место задания — сразу после титульного листа (в структуре курсовой), вкладывается пользователем.
